# Q3 – Analysis

## Objective
To understand safe resource handling and debugging techniques in Java.

## Methods Compared

1. Manual closing using finally.
2. Automatic closing using try-with-resources.

## Observations
- The sample file was created successfully.
- File contents were read correctly.
- Try-with-resources automatically closed the file resources.
- IOException was handled using catch blocks.

## Advantages
- Prevents resource leaks.
- Reduces manual cleanup code.
- Improves readability.
- Makes programs more reliable.

## Conclusion
Try-with-resources is a safer and simpler approach for managing files in Java.
