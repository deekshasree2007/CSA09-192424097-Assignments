## Project Description

The Campus Smart Parking System is designed to manage parking facilities across multiple floors.

The system supports different vehicle types, parking slot allocation, ticket generation and parking fee calculation.

It demonstrates important Object-Oriented Programming concepts such as:

- Classes and Objects
- Encapsulation
- Inheritance
- Polymorphism
- Abstraction
- Method Overriding
- Packages and Access Modifiers
- Static Members
- Arrays and Data Structures

## How to Compile and Run Java Programs

Open the terminal in the folder containing the Java file.

For example, to run the ParkingFacility program:

```bash
javac ParkingFacility.java
java ParkingFacility
```

To run the FeeDemo program:

```bash
javac FeeDemo.java
java FeeDemo
```
